    云同步

    未连接 连上后，每次改动会自动备份到你的私有 Gist
    只需要 Gists 权限，存在本机，不会写进网页文件，可随时在 GitHub 撤销。
    怎么拿到这个令牌？（一次性，约 2 分钟）
    1. 电脑或手机打开 github.com → 右上头像 → Settings
    2. 左侧最下 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
    3. 起个名字，有效期选 No expiration（一次配好不用再换）；Repository access 选 Public repositories (read-only)；Account permissions 里找到 Gists，改成 Read and write
    4. 点 Generate token，复制那一串（只显示一次），粘到上面
    5. 以后换手机 / 重装：粘同一个令牌即可，App 会自动找到原来的备份接上，不会新建一份
